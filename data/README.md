# Datasets

This directory describes how to obtain and place the datasets used by the training pipeline.

## Speech Emotion Recognition (SER)

Four public datasets are combined. After downloading, organize as:

```
combined_ser_dataset/
├── angry/
│   ├── 1001_DFA_ANG_XX.wav
│   ├── ...
├── disgust/
├── fear/
├── happy/
├── sad/
├── surprise/
├── neutral/
└── metadata.csv    # generated by scripts/build_ser_metadata.py
```

### Sources

* **CREMA-D** — https://github.com/CheyneyComputerScience/CREMA-D
* **RAVDESS** — https://zenodo.org/record/1188976
* **SAVEE** — http://kahlan.eps.surrey.ac.uk/savee/Download.html
* **TESS** — https://tspace.library.utoronto.ca/handle/1807/24487

License: per the individual dataset licenses. CREMA-D is CC-BY-4.0; RAVDESS is CC-BY-NC-SA-4.0; SAVEE and TESS are academic-research use.

## Facial Expression Recognition (FER)

* **FER2013** — https://www.kaggle.com/datasets/msambare/fer2013

Organize as:

```
fer2013/
├── train/
│   ├── angry/
│   ├── disgust/
│   ├── fear/
│   ├── happy/
│   ├── sad/
│   ├── surprise/
│   └── neutral/
└── test/
    └── (same structure)
```

`train_fer_tensorflow.py` reads `FER_TRAIN_DIR` and `FER_TEST_DIR` from `config.py` (or environment variables).

## Text Emotion Recognition (TER)

Four datasets are combined. After downloading, place as CSV files:

* **DailyDialog** — http://yanran.li/dailydialog.html
* **MELD** — https://github.com/SenticNet/MELD
* **EmoryNLP** — https://github.com/emorynlp/emory-emotional-context
* **IEMOCAP** — https://sail.usc.edu/iemocap/

Expected CSV columns (flexible, see `load_text_csv()` in `train_ter_pytorch.py`):

```
text,emotion
"some utterance",happy
"another utterance",sad
```

`train_ter_pytorch.py` reads `TEXT_TRAIN_CSV` and `TEXT_VAL_CSV` from `config.py` (or environment variables).

---

## Notes on class harmonization

All datasets are mapped to a unified 7-class emotion taxonomy:

```
angry, disgust, fear, happy, sad, surprise, neutral
```

Synonyms like "anger" → "angry", "happiness" → "happy", "calm" → "neutral" are mapped automatically by `map_emotion_to_unified()` in the training scripts.
